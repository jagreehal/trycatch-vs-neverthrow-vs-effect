Move linting to oxlint, adopt TypeScript 7, and let the analyzers draw the docs.

- Linting runs on oxlint with type-aware rules through oxlint-tsgolint. `eslint-plugin-awaitly` loads as a JS plugin, so the awaitly rules keep their names.
- TypeScript 7.0.2 with `@effect/tsgo`, which patches `tsc` to report Effect diagnostics during typecheck.
- Dependencies on their latest releases: awaitly 6.1, awaitly-analyze 0.31, effect-analyzer 3.6, vitest 5, zod 4.6.
- The payment workflow calls its provider through `step.fromResult`, with the audit write in `onError`, so the analyzer maps every step and error edge.
- The Effect pipeline and checkout use `Effect.forEach`, which the analyzer reads as a named loop.
- README, ADVANCED, and the scenario docs carry diagrams generated by `awaitly-analyze` and `effect-analyze`, with refreshed bundle sizes and release notes through awaitly 6.1.
